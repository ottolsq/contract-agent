## 处理说明

- 技术开发合同：从官方 `.doc` 的 `WordDocument` 流抽取文本，**不是手工转录**。只做四件事——丢弃头部 FIB 噪声、把制表符当空格（它是填空位的分隔，不是换行）、保留段落标记、折叠连续空白；条款文字未改动
- 劳动合同：按 `.gov.cn` 页面内容逐条转录，未改动条款文字
- 两份都只收正文，不含附件与登记页：技术开发合同到第二十九条及签署页为止；劳动合同到第二十五条为止，**不收附件 1「续订劳动合同」和附件 2「变更劳动合同」**——那是独立协议
- `.doc` 原件不入库（`.gitignore` 已排除），需要时按上表链接重新下载

## 抽取准确性怎么验的

`.doc` 是 Word 97 二进制格式，没有现成解析库，抽取过程必须自证没有丢字。用了三项独立检查：

| 检查 | 方法 | 结果 |
|---|---|---|
| **字数对账** | 从 FIB 读 `fcMin/fcMac` 还原正文，统计汉字与标点数，与落盘样本比 | 汉字 **2801 = 2801**，标点 **381 = 381** |
| **字符多重集** | 原件与样本的非空白字符做多重集差 | 样本零多余；原件多出的 22 个非空白字符全是 Word 域代码（`PAGE` / `MERGEFORMAT`）与控制符，属主动截断 |
| **顺序校验** | 样本非空白串是否为原件非空白串的子序列 | 通过（3335 个字符全部按序匹配）——只删了空白，没有重排、没有替换 |

两点说明：

- **段落数不同**（原件 271 段 → 样本 201 行）只是版式差异：空段被丢弃、连续空白被折叠。正文段落与条款边界不受影响，切分回归 29 条全对
- 原件模板本身有一处错字：第二十一条「具体相关利益的分配**办**如下」漏了「法」字（同条下一句是「分配**办法**」）。这处**在原件里就是这样**，不是抽取丢字——汉字总数完全吻合可以证明

`.doc` 原文里还带页脚域代码（`PAGE` / `MERGEFORMAT`）和二进制尾巴，抽取时在最后一个「年 月 日」处截断。

## 对外样本适合演示什么

技术开发合同是科技公司对外合同里条款密度最高的一类，这份文本覆盖了审查清单上的主要项：

| 条款 | 内容 |
|---|---|
| 第十一条 | 保密义务（内容、人员范围、期限、责任） |
| 第十二、十三条 | 成果交付与验收标准 |
| 第十四条 | 侵权担保（第三人指控时研究开发人的责任） |
| 第十五、十六、二十一条 | 知识产权归属、禁止提前转让、后续改进成果 |
| 第二十条 | 违约责任（六项，全部留空） |
| 第二十三、二十四条 | 解除条件与争议解决 |

**现成的结构性缺口**：第二十条六项违约责任全部留空，等于违约救济没有约定，属于审查报告里应提示的"条款存在但实质缺失"。

另有一类空白范本共有的问题：第十五条的知识产权归属、第十六条之外的多处选项（买卖双方谁享有申请专利的权利、成果归谁所有）全部未勾选，审查要能识别"选项未选"而不是当作已约定。

## 对内样本适合演示什么

人社部《劳动合同（通用）》覆盖劳动合同法定必备条款，与语料里的劳动法域（劳动法 / 劳动合同法 / 社会保险法 / 工伤保险条例等）逐条对得上：

| 条款 | 内容 | 对应法条方向 |
|---|---|---|
| 第一、七条 | 合同期限、试用期及其工资 | 劳动合同法第 19、20 条（试用期上限、试用期工资下限） |
| 第三、四、五条 | 工时制度、加班、休假 | 劳动法第 36、41、44 条 |
| 第六、八条 | 工资支付方式与时间 | 劳动法第 50 条、工资支付暂行规定 |
| 第九至十一条 | 社会保险、工伤与医疗期待遇 | 社会保险法、工伤保险条例 |
| 第十三、十四条 | 劳动安全卫生、女职工特殊保护 | 劳动法第 52–65 条、女职工劳动保护特别规定 |
| 第十七、十八条 | 解除时的经济补偿与档案转移 | 劳动合同法第 46、50 条 |
| 第十九、二十条 | 保密 / 竞业限制 / 服务期 | 劳动合同法第 23、24 条 |

**它自带的一类问题**：空白范本，第一条、第三条、第六条、第七条的关键选项全部未勾选、金额与期限全部为空——审查要能识别"条款存在但实质未约定"。

## 两份样本的分工

| | 技术开发（委托）合同 | 劳动合同（通用） |
|---|---|---|
| 合同类型 | 对外（external） | 对内（internal） |
| 条款数 | 29 | 25 |
| 制定机关 | 工业和信息化部 | 人力资源社会保障部 |
| 主要法域 | civil + tech | labor + tech |
| 典型问题 | 第二十条违约责任全空；多处选项未勾选 | 关键选项未勾选、金额期限未填 |

界面演示时两种模式各跑一份，正好验证"分类 → 选域 → 逐条检索"这条链路的分支。
